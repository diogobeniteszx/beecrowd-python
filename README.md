# Beecrowd - Python

Repositório criado para armazenar minhas **soluções de problemas e exercícios realizados na plataforma beecrowd**, utilizando a linguagem **Python**.

Os exercícios estão organizados por conteúdos, abordando desde conceitos básicos de programação até estruturas de repetição e arrays.

## Conteúdo

### Básicos 1

Conteúdos relacionados aos primeiros conceitos de programação, como:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores
* Operações matemáticas
* Expressões

### Básicos 2

Conteúdos relacionados ao aprofundamento dos conceitos básicos, incluindo:

* Operações matemáticas
* Conversão de tipos
* Manipulação de dados
* Expressões
* Resolução de problemas

### Estruturas de Controle e Decisão

Conteúdos relacionados ao controle do fluxo dos programas, incluindo:

* Estruturas condicionais
* if
* elif
* else
* Operadores relacionais
* Operadores lógicos
* Condições aninhadas

### Repetição - for

Conteúdos relacionados às estruturas de repetição utilizando for, como:

* Estrutura for
* range
* Contadores
* Acumuladores
* Repetições controladas

### Repetição - while

Conteúdos relacionados às estruturas de repetição utilizando while, incluindo:

* Estrutura while
* Condições de parada
* Contadores
* Acumuladores
* Repetições condicionais

### Arrays Uni e Multidimensionais

Conteúdos relacionados ao armazenamento e manipulação de conjuntos de dados, como:

* Arrays unidimensionais
* Arrays multidimensionais
* Listas
* Índices
* Percorrimento de estruturas
* Manipulação de elementos

## Objetivo

Este repositório tem como objetivo **registrar minha evolução nos estudos de programação e Python**, reunindo as soluções dos problemas e exercícios realizados na plataforma beecrowd.

## Plataforma

Plataforma de exercícios e problemas de programação - **beecrowd**
